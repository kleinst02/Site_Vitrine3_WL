# T-003 : Revue Design System
Agent : agent-reviewer
Depend de : T-001, T-002
Fichiers autorises : /src/ui/ (lecture seule)
Objectif : Auditer le design system (tokens + composants generiques) sur la coherence visuelle, l'accessibilite WCAG AA, la responsivite et la qualite du code HTML/CSS.
Criteres d'acceptation :
- [ ] Tokens complets et coherents (pas de valeurs magiques)
- [ ] Composants utilisent exclusivement les tokens
- [ ] Contrastes couleurs conformes WCAG AA (ratio >= 4.5:1 texte, >= 3:1 elements larges)
- [ ] Navigation au clavier fonctionnelle (focus visible, tabindex logique)
- [ ] Aria-labels et roles semantiques presents
- [ ] Responsive : pas de debordement mobile, menu hamburger fonctionnel
- [ ] Code propre, sans duplication, bien commente
- [ ] Rapport de revue ecrit dans /.tasks/T-003-report.md
Statut : a faire
