# T-002 : Composants generiques UI
Agent : agent-ui
Depend de : T-001
Fichiers autorises : /src/ui/components/
Objectif : Creer les composants generiques reutilisables du design system : boutons, liens, cartes, badges, navigation (header + menu mobile), footer, section wrapper, conteneur, typographie, separateurs.
Criteres d'acceptation :
- [ ] Boutons : primaire, secondaire, outline, ghost, avec etats hover/focus/disabled
- [ ] Carte generique : image optionnelle, titre, texte, CTA
- [ ] Header responsive : logo, navigation desktop, menu hamburger mobile
- [ ] Footer : colonnes liens, copyright, liens sociaux
- [ ] Section wrapper : conteneur centre avec variantes de padding
- [ ] Composant typographie : titres, paragraphes, listes
- [ ] Tous les composants utilisent les tokens de T-001
- [ ] HTML semantique, accessibilite WCAG AA (focus visible, aria-labels)
- [ ] Classes Tailwind CSS coherentes
Statut : a faire
