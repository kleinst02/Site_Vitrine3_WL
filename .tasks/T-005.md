Objectif : Implementer l'API REST pour le formulaire de contact : validation des donnees, stockage en BDD, envoi d'email de notification, protection anti-spam.
Criteres d'acceptation :
- [ ] POST /api/contact : reception et validation du formulaire
- [ ] Validation serveur : nom (2-100 car.), email valide, sujet (5-200 car.), message (10-5000 car.), lang (fr|en)
- [ ] Stockage en BDD table contacts
- [ ] Envoi email notification via nodemailer (configurable SMTP)
- [ ] Email de confirmation a l'expediteur (template FR ou EN selon lang)
- [ ] Rate limiting : max 3 soumissions / IP / heure
- [ ] Protection CSRF
- [ ] Reponses JSON avec messages d'erreur localises (FR/EN)
- [ ] Codes HTTP corrects : 201 succes, 400 validation, 429 rate limit, 500 erreur serveur
