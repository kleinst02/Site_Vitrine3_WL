# T-010 : Composants Blog
Agent : agent-composants
Depend de : T-002, T-006
Fichiers autorises : /src/components/blog/
Objectif : Creer les composants metiers du blog : carte article (apercu), liste paginee, vue article complet, navigation entre articles, filtre categories.
Criteres d'acceptation :
- [ ] Carte article : image, titre, extrait, date, categorie, lien "lire la suite"
- [ ] Liste articles : grille responsive de cartes avec pagination
- [ ] Pagination : boutons precedent/suivant, numero de page, appel API
- [ ] Vue article complet : titre, date, categorie, contenu HTML (depuis Markdown), auteur
- [ ] Navigation : article precedent/suivant
- [ ] Tous les textes (labels, boutons) en FR et EN
- [ ] Utilise les composants generiques de /src/ui/components/
- [ ] Rendu HTML du Markdown stylise avec Tailwind typography
Statut : termine
