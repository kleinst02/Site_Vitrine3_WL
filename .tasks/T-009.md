# T-009 : Composant Formulaire de Contact
Agent : agent-composants
Depend de : T-002, T-005
Fichiers autorises : /src/components/contact/
Objectif : Creer le composant formulaire de contact interactif avec validation front-end, gestion d'etats (envoi, succes, erreur), appel API, et support i18n FR/EN.
Criteres d'acceptation :
- [ ] Champs : nom, email, sujet, message avec labels et placeholders
- [ ] Validation front-end en temps reel (memes regles que le back-end)
- [ ] Messages d'erreur sous chaque champ invalide
- [ ] Etats visuels : vide, en cours de saisie, erreur, envoi en cours (spinner), succes
- [ ] Appel POST /api/contact avec fetch API
- [ ] Message de confirmation apres envoi reussi
- [ ] Tous les textes disponibles en FR et EN
- [ ] Utilise les composants UI de /src/ui/components/ (boutons, inputs)
- [ ] Accessible : labels associes, aria-describedby pour erreurs, focus management
Statut : termine
