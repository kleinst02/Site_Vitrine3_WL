# Règles responsive de référence

- Mobile-First : styles de base pour 320 px, surcharges via `sm:`/`md:`/`lg:`/`xl:`.
- Aucun défilement horizontal de 320 px à 1920 px.
- Cibles tactiles ≥ 44 × 44 px.
- Texte corps ≥ 16 px ; longueur de ligne 45–75 caractères.
- Images : `max-width: 100%`, dimensions explicites, `loading="lazy"` hors écran initial.
- Focus clavier visible sur tout élément interactif ; ordre de tabulation logique.
- Contraste ≥ 4,5:1 (texte), ≥ 3:1 (grand texte, icônes, bordures de champs).
- Respecter `prefers-reduced-motion`.
