# Cadrage de projet

1. Relire `CLAUDE.md` (stack, standards, sécurité).
2. Extraire du besoin : objectifs, public cible, pages, fonctionnalités, contenus, contraintes (délai, SEO, langues).
3. Poser à l'humain au plus 5 questions, uniquement bloquantes.
4. Classer les fonctionnalités : indispensable / souhaitable / plus tard.
5. Écrire `/.tasks/ROADMAP.md` avec : objectif, périmètre, hors-périmètre, jalons (Design → Back-end → Assemblage → QA → Validation humaine), risques.
6. Lister les hypothèses faites et les faire confirmer.

Sortie : `ROADMAP.md` d'une page maximum.
